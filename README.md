# MUMU PWA

기존 HTML 프로토타입에 설치 설정을 추가한 버전입니다.

- ZIP을 풀고 내용물 전체를 GitHub 저장소 루트에 업로드하세요.
- Vercel에서 GitHub 저장소를 Import. Framework Other, Root ./, Build Command 비움, Output Directory . 로 배포하세요.
- iPhone: Safari → 공유 → 홈 화면에 추가 → 웹 앱으로 열기(표시되는 경우). Android: Chrome → 메뉴 → 앱 설치 또는 홈 화면에 추가.
- 추후 수정 시 기존 저장소 main 브랜치 파일을 갱신하면 동일 Vercel 프로젝트에서 재배포됩니다. sw.js 캐시 버전도 필요시 갱신하세요.
- 현재는 로컬 저장 기반 시연용입니다. 실제 로그인·커플 동기화·AI 분석은 미연동입니다. 개인 데이터와 비밀 키는 공개 HTML에 넣지 마세요.
- 기존 글꼴은 로컬 설치 폰트를 참조하므로 모바일에 해당 폰트가 없다면 대체 글꼴이 표시됩니다.
